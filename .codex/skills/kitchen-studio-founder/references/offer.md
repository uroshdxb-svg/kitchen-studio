# Offer: remove a real obstacle

Read observed operator feedback, competitor workarounds and the current pilot terms. List obstacles before, during and after the useful concept. Tag rehearsal ideas as simulated, inferred obstacles as hypotheses and actual objections with their source.

Describe the core outcome and the minimum inputs/operator effort. For each extra, record which objection it answers, delivery time, variable cost and dependencies. Favor a short supported trial, clear inputs and a usable supplier-review handoff over a large bonus stack.

Check the exact supported scope with Product/Equipment. Do not promise approvals, engineering accuracy, installation clearance or savings that were not verified. Model any proposed guarantee/refund exposure before presenting it; a draft is not a founder commitment.

Keep only real scarcity tied to actual capacity and a genuine deadline. Preserve prior pitch/offer versions and compare rehearsal changes qualitatively. Evaluate real variants using actual exposure/reply/session data; do not label a synthetic before/after as a conversion lift.

Return one concise offer, its delivery costs, excluded/unknown scope, objection-to-proof map and the smallest test. Outreach owns a concrete public-source recruitment batch; messages use the acquisition ledger's release controls.
