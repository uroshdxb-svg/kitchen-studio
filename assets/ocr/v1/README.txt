Self-hosted OCR browser assets, loaded only when reading an image.

Tesseract.js 6.0.1 and Tesseract.js-core 6.1.2: Apache-2.0.
https://github.com/naptha/tesseract.js
https://github.com/naptha/tesseract.js-core

English 4.0.0_best_int language data from @tesseract.js-data/eng 1.0.0.
The npm wrapper declares MIT; the underlying trained data is Apache-2.0:
https://github.com/naptha/tessdata
https://raw.githubusercontent.com/naptha/tessdata/gh-pages/LICENSE

Upstream files are unmodified. sources.json records registry package integrity
and original asset SHA-256 hashes. Keep all four core variants so the reader
can select the appropriate runtime. New asset versions require a new directory
because /app/vendor/ is cached immutably.
